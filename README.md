# Quark Reflex（夸克助手桌面小窗）

把「夸克助手」装进一个置顶小窗：`Ctrl+Space` 一键呼出，随时问、随手收，不打断当前工作。基于 Rust（tao + wry + WebView2）构建，单文件、体积小、内存占用低。

## 功能特性

- **全局热键呼出/隐藏**：默认 `Ctrl+Space`（可在设置中自定义）
- **窗口置顶**：图钉一键切换，小窗始终悬浮在其他窗口之上
- **双档尺寸**：紧凑小窗 / 阅读大窗一键切换，位置与尺寸自动记忆
- **系统托盘**：最小化到托盘，右键菜单（显示 / 设置 / 获取登录凭证 / 退出）
- **真实账号数据**：与夸克 PC 浏览器共享登录态，会话历史、模型列表全部同步
- **无边框圆角外观**，深浅色自适应系统

## 系统要求

- Windows 10 1809 及以上（x64）
- 已安装并**登录**[夸克 PC 浏览器](https://www.quark.cn/)（小窗通过它完成签名与消息收发）

## 下载安装

从 [Releases](../../releases) 页面下载 `QuarkReflex-Setup-x.x.x.exe`，双击安装，桌面生成「夸克助手」快捷方式。

> 首次运行下载的安装包时，Windows SmartScreen 可能提示"已保护你的电脑"（未购买代码签名证书所致）。点击「更多信息」→「仍要运行」即可。

## 使用说明

| 操作 | 方式 |
|---|---|
| 呼出 / 隐藏小窗 | `Ctrl+Space`（全局热键） |
| 置顶开关 | 标题栏 📌 按钮 |
| 切换紧凑 / 阅读尺寸 | 标题栏尺寸按钮 |
| 设置（热键、关闭行为等） | 托盘图标右键 → 设置 |
| 退出 | 托盘图标右键 → 退出 |

**常见问题**

- **首次启动会自动重启夸克浏览器？** 小窗需要通过浏览器的本地调试端口完成签名桥接。若浏览器未以调试模式运行，小窗会自动重启它（登录态不受影响）。
- **发消息没反应？** 确认夸克 PC 浏览器内已登录夸克账号；仍异常时，托盘右键 →「获取登录凭证」重新抓取。
- **卸载会清掉什么？** 卸载时会一并删除 `%APPDATA%\QuarkReflex`（含本地缓存的登录凭证与配置），不留隐私残留。

## 工作原理

小窗加载的是夸克助手官方网页（WebView2）。由于该网页的签名参数（sign_wg / vcode）无法在网页环境内自行生成，Quark Reflex 会：

1. 以调试端口方式拉起本机夸克浏览器；
2. 在其中打开一个真实助手页，通过 CDP（Chrome DevTools Protocol）把签名计算、CMS 配置、AI 消息收发**实时转发**到真实浏览器执行；
3. 将本机登录凭证（cookie）仅写入本地 `%APPDATA%\QuarkReflex`，不经过任何第三方服务器。

即：所有请求都由你的浏览器、以你的账号身份发出，本工具不含任何服务端组件。

## 从源码构建

```bash
# 前置：Rust stable 工具链
cargo run --example gen-icon   # 生成 assets/icon.ico（首次必须）
cargo build --release          # 产出 target/release/quark-reflex.exe

# 生成安装包（需安装 Inno Setup 6）
"c:\Program Files (x86)\Inno Setup 6\ISCC.exe" quark-reflex.iss
# 产出 dist/QuarkReflex-Setup-x.x.x.exe
```

调试环境变量：`QR_PROBE=1`（输出页面诊断日志到 `%APPDATA%\QuarkReflex\chat-verify.log`）。
