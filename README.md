## 为什么用它

| 能力 | 带来的便利 |
| --- | --- |
| 随时唤起 | 全局快捷键打开 / 收起同一个聊天窗口，保留当前对话。 |
| 置顶陪伴 | 一边看文档、网页或代码，一边问问题；置顶开关就在标题栏。 |
| 真实账号数据 | 与夸克 PC 浏览器共享登录态，官网账号、历史会话、模型列表全部同步；不需要单独申请 API Key。 |
| 双档尺寸 | 紧凑小窗随手问，阅读大窗看长回答；一键切换，位置与尺寸自动记忆。 |
| 顺手的设置 | 独立面板配置热键、关闭行为；可自定义唤起键。 |
| 系统托盘 | 收进托盘常驻后台；右键菜单含显示、设置、获取登录凭证、退出。 |
| 轻量原生 | Rust（tao + wry + WebView2）构建，单文件 ~2 MB，无自建服务器、无遥测。 |

适合查资料时快速追问、阅读外文时翻译段落、写代码时问一个短问题。

## 适用范围与限制

它解决的是"想问夸克助手，还要切换到浏览器找标签页"的小麻烦：快捷键唤出同一个窗口，问完收起，继续工作。窗口与交互由本工具提供，回答、账户与会话历史由夸克服务提供。

- **仅支持 Windows 10/11 x64**，且需要已安装并**登录**[夸克 PC 浏览器](https://www.quark.cn/)（本工具通过它完成签名与消息收发，见[工作原理](#工作原理)）。
- 首次启动若检测到夸克浏览器未以调试模式运行，会**自动重启夸克浏览器**（登录态不受影响）。
- 官网改版、签名算法变更或服务策略调整都可能让小窗暂时不可用；不承诺持续可用。
- 当前发行包未做代码签名，首次运行可能触发 SmartScreen 提示（见下文安装说明）。

## 下载与安装

在 [Releases](../../releases/latest) 下载：

| 文件 | 怎么用 |
| --- | --- |
| `QuarkReflex-Setup-x.x.x.exe` | 双击安装；当前用户安装，无需管理员权限；可选桌面快捷方式，可从 Windows 应用列表卸载。 |

安装完成后桌面出现「夸克助手」快捷方式，点击即可打开。要求 **Windows 10/11 x64** 与系统自带 WebView2 运行时（Win10 1809+ 一般已具备）。

当前发行包未签名，浏览器或 Windows 可能提示"未知发布者"。请只从本仓库 Releases 页面下载，必要时核对哈希：

```powershell
Get-FileHash .\QuarkReflex-Setup-0.1.0.exe -Algorithm SHA256
```

卸载时会一并删除 `%APPDATA%\QuarkReflex`（含本地登录凭证与配置），不留隐私残留。

## 快速上手

1. 首次打开，工具会自动拉起（或重启）夸克浏览器并抓取本机登录凭证，随后自动刷新聊天页。
2. 按 <kbd>Ctrl</kbd>+<kbd>Space</kbd> 唤出 / 收起小窗。
3. 标题栏依次为置顶 📌、尺寸切换；右侧为设置入口。
4. 热键与其他软件冲突时，在设置中点击按键框录入新组合键。
5. 发消息没反应？确认夸克 PC 浏览器内已登录；仍异常时，托盘右键 → **获取登录凭证** 重试。

## 工作原理

小窗加载的是夸克助手官方网页（WebView2）。由于该网页的签名参数（sign_wg / vcode 等）只能在夸克浏览器环境中生成，Quark Reflex 会：

1. 以调试端口（CDP，Chrome DevTools Protocol）方式拉起本机夸克浏览器；
2. 在其中打开一个真实助手页，把签名计算、CMS 配置、AI 消息收发**实时转发**到真实浏览器执行；
3. 在页面内补齐夸克浏览器特有的 `chrome.*` 扩展接口，使官方网页正常渲染。

即：所有请求都由你自己的浏览器、以你自己的账号身份发出，本工具**不含任何服务端组件、不经过任何第三方服务器**。

## 数据与隐私

- 登录凭证（cookie 等）仅保存在本地 `%APPDATA%\QuarkReflex`，只在本机浏览器与本地小窗之间流转，不对外上传。
- 直接访问夸克官方页面，不反代、不替换聊天 API、不额外转发对话内容。
- 不含遥测、统计或崩溃上报服务；本地日志（`grab-debug.log`）仅记录桥接流程，超 2 MB 自动轮转。
- 卸载即清理全部本地数据。

## 从源码构建

```bash
# 前置：Rust stable 工具链
cargo run --example gen-icon   # 生成图标与 logo（首次必须）
cargo build --release          # 产出 target/release/quark-reflex.exe

# 生成安装包（需安装 Inno Setup 6）
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" quark-reflex.iss
# 产出 dist/QuarkReflex-Setup-x.x.x.exe
```

调试环境变量：`QR_PROBE=1`（输出页面诊断日志到 `%APPDATA%\QuarkReflex\chat-verify.log`）。
